
1.   進入sc界面  （设置完毕后，保存sc到当前工程）
  
      点中左边的adc12  -- 点击ADD  --   会自动跳出 ADC12_0

     sample clock config设置：
        ADC Clock source：       SYSOSC     (其他时钟源也应该可以考虑)    //默认32M
        sample clock divider：   divide by 1     //默认32M

    sample mode configuration设置：
       conversion mode：                 sequence
       conversion starting address：  0
       conversion end address：       1

       enable repeat mode:              暂不勾选
       tigger source          ：            software    （不使用定时器事件自动触发）


    adc conversion mem confiurations 设置：
       memory 0 设置：
          name：              0
          input channel：        channel2
          reference voltage ： VDDA    (默认)
          sample period source：  sampling timer0    (默认)

          optional  configuration 设置：
              trigger mode：  trigger will auto step to  next memory converson register    (一个通道转换结束后，会自动触发下一个通道)

       memory 1,2,3 设置：   (同理 memory 0  设置不同的adc引脚)
          ......


    advanced configuration设置：
       conversion resolution：  12-bits             (默认)
       powerdown mode:     manual          (默认)
       desired sample time 0:   40 us        

    interrupt configuration设置：
       enable interrupts：     mem1 result loaded interrupt 
       interrupt priority；     default                  (默认)


    Pinmux 设置：
        adc12 peripheral：    ADC0
        adc12 channel 2 pin： PA25/26        //adc0-2
        adc12 channel 5 pin： PB24/23        //adc0-5


2. keil 魔法棒中设置：  勾选 “reset and run”


3. 在main.c中添加下面的代码

         volatile bool gCheckADC;
         volatile uint16_t iadcval0;
         volatile uint16_t iadcval1;


         int main(void)
         {
             SYSCFG_DL_init();

             
             //adc init
             NVIC_EnableIRQ(ADC12_0_INST_INT_IRQN);
             

             while (1) 
             {
                 delay_cycles(32000000);
                 
                 gCheckADC  = false;
                 DL_ADC12_startConversion(ADC12_0_INST);

                 while (gCheckADC == false);
          
                 iadcval0 = DL_ADC12_getMemResult(ADC12_0_INST, DL_ADC12_MEM_IDX_0);
                 iadcval1 = DL_ADC12_getMemResult(ADC12_0_INST, DL_ADC12_MEM_IDX_1);
                 
                 DL_ADC12_enableConversions(ADC12_0_INST);
                 
                 sprintf(txBuf, "adc01 %d %d\r\n", iadcval0, iadcval1 );
                 SendString(txBuf);       

             }
         }


         void ADC12_0_INST_IRQHandler(void)
         {
             switch (DL_ADC12_getPendingInterrupt(ADC12_0_INST)) {
                 case DL_ADC12_IIDX_MEM1_RESULT_LOADED:
                     gCheckADC = true;
                     break;
                 default:
                     break;
             }
         }
