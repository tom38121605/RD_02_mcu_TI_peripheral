
1.   進入sc界面  （设置完毕后，保存sc到当前工程）
  
    点中左边的TIMER  -- 点击ADD  --   会自动跳出TIMER_0  

     name：                           TIMER_0      
     selected peripheral：       TIMA0     

     timer profiles：   customer   （默认）

 

    basic config 设置：
       timer clock source：  BUSCLK                        //32M
       timer clock divider:   divided by 2                   //16M
  
       timer clock precaler:   256

       timer clock frequency:  62.5KHz             （自动计算而出）
       timer period range:  x - y  ms             （自动计算而出）

       timer mode:  periodic down conting      (默认)
       desired  timered period：   1s 

    interrupt config 设置：
       enable interrupt：  zero event   

    Pinmux 设置：
       timer peripheral：  TIMA0   


2. keil 魔法棒中设置：  勾选 “reset and run”


3. 在main.c中添加下面的代码
         #include "ti_msp_dl_config.h"

         int main(void)
         {
             SYSCFG_DL_init();
             
             NVIC_EnableIRQ(TIMER_0_INST_INT_IRQN);
             
             DL_TimerA_startCounter(TIMER_0_INST);

             while (1) 
             {

             }
             
         }

         void TIMER_0_INST_IRQHandler(void)
         {

             DL_TIMER_IIDX AAA = DL_TimerA_getPendingInterrupt(TIMER_0_INST);
             
             switch (AAA)
             {
                case DL_TIMER_IIDX_ZERO:
                
                   DL_GPIO_togglePins(LED_PORT,LED_PIN_0_PIN);
                   break;
                   
                default:
                
                   break;          
             }

         }
